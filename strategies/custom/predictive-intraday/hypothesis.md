# Hypothesis

A qualified opening-range breakout, accepted by the bounded Jev decision and rejected when evidence is insufficient, can be traded as a same-session paper position under the existing one-share limits.

What the code does is that sequence. What it does not show is a measured edge. Fresh-bar fallback refuses a remembered order when the new bar is no longer the same setup. Learning can store outcomes and study temporary abstention. It does not raise risk caps.

Failure conditions: stale bars, a Jev response that fails validation, missing protection after a fill, unexplained account history, and any path that would hold through the close.
