## One finish line

A timestamped opportunity becomes a point-in-time evidence packet and validated Athena context; code supplies numbers and supported actions; **Astra 6** proposes an evidence-linked thesis/scenarios/plan; **Jev** judges a bounded choice using original evidence plus proposal; deterministic risk authorizes the exact intent; broker events confirm execution; deterministic APDE enforcement manages exposure; an attributed episode feeds replay, validation and versioned knowledge. Both arms must demonstrate that complete path.

Critical protection, kill switches and emergency/session exits never wait for either model. Aggressive operation means valid opportunity capture and adaptive winner management within existing limits, not raising caps or taking otherwise forbidden risk. No return or learning-improvement guarantee is made.
